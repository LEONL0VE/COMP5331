Parameter stability

Columns vary ε by −10%, 0%, +10%; rows vary MinPts by −1, 0, +1 (deduplicated at 1). Each cell refits the original data and checks the same endpoint. Both methods use the same boundary tolerance: 10⁻¹⁰ × max(1, ε).

What is guaranteed?

If the endpoint is within ε−ρ of a target core, any Euclidean perturbation up to ρ stays within that core's ε ball. The displayed radius is the computed certificate, which may differ by floating-point rounding. This is sufficient, not a maximal certificate for the union of balls. It does not promise unique membership or unchanged clustering after moving the data.

Stability is a finite-grid test, not a probability. Target identity uses member overlap (Jaccard ≥ 0.5); split, merged, disappeared and weak-overlap targets are marked unresolved and count as not passed.
